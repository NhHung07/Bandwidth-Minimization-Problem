# Báo cáo Assignment 2

Đặt mã nguồn LaTeX, hình và tài liệu cần cho bản báo cáo ở đây khi bắt đầu viết. Assignment 2 yêu cầu báo cáo dạng bài báo khoa học theo file mẫu của môn học và lớp Elsevier `cas-sc`, ví dụ `\documentclass[a4paper,fleqn]{cas-sc}`.

Phần thực nghiệm cần dùng dữ liệu trong `results/data/` và hình tạo bằng `cnsplots`. Mục **Data Availability** cần có đường dẫn repository chứa mã nguồn và kết quả. Xem [WORKFLOW.md](../WORKFLOW.md) để biết nội dung và số liệu cần thu thập trước khi viết.
